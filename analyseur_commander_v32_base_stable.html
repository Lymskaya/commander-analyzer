Atelier de deckbuilding

Diagnostic Commander

Collez votre liste, indiquez votre/vos commandant(s), et l'outil interroge Scryfall pour disséquer la courbe de mana, la base de mana, les catégories fonctionnelles (rampe, pioche, interaction…) et la légalité de couleur — comme on étale ses cartes sur la table pour les compter une à une.

Votre liste

Une carte par ligne. Les formats "1 Sol Ring", "1x Sol Ring" ou juste "Sol Ring" fonctionnent ; les en-têtes d'export (Moxfield, Archidekt…) et les codes d'édition sont ignorés automatiquement.

Connexion Internet requise. Pour éviter les blocages du navigateur, utilisez de préférence cette page via http://localhost plutôt qu'en file://.

Conseil : si Scryfall ne répond pas, ouvrez la console du navigateur (F12) pour voir le détail technique de l'erreur.
